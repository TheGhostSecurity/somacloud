What This Does

Installs Docker Engine on the worker (Ubuntu/Debian or CentOS/RHEL)

2

Generates a TLS keypair and sends a CSR to the app server for signing

3

4

Joins the Docker Swarm cluster as a worker node

5

Prerequisites on the worker EC2 instance:

  • Ubuntu 20.04+ or Amazon Linux 2+
  • Port 22 open from the app server (SSH)
  • Port 2376 open from the app server (Docker API)
  • Port 2377 open from the app server (Swarm join)
