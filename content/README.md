# SomaCloud Content

Content is organized as:

```text
content/
  learning-path-slug/
    path.yaml
    module-slug/
      module.yaml
      activity-slug/
        activity.yaml
        theory.md
        practice.md
        sandbox.yaml
        challenge.md
        reflection.md
        assessment.json
```

`sandbox.yaml` is optional. When it is absent, the Sandbox stage is not created for that activity.

Long lesson content belongs in these files, not in database text fields.
